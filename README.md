# SQL-проекты: анализ данных для транспортных средств, гоночных автомобилей, гостиничных бронирований и структуры компании

## Описание проекта

Данный репозиторий содержит 4 самостоятельных SQL-проекта, демонстрирующих навыки:

- Проектирования схем баз данных (DDL)
- Наполнения тестовыми данными (DML)
- Написания аналитических запросов разной сложности (DQL)
- Использования оконных функций, CTE, рекурсивных запросов и оптимизации

Каждый проект решает реальную бизнес-задачу.

---

## Цели и задачи

### Цель
Показать владение SQL на уровне, достаточном для позиции Data Analyst / Junior SQL Developer.

### Задачи
1. Спроектировать и развернуть базы данных.
2. Написать чистые, документированные запросы.
3. Решить конкретные аналитические задачи.
4. Обеспечить воспроизводимость результатов.

## Структура базы данных и основные функции

### DB 1: Магазин транспортных средств (Vehicle Shop)
- **Таблицы**: `vehicle`, `car`, `motorcycle`, `bicycle`
- **Связи**: `vehicle.model` → специализированные таблицы (car/motorcycle/bicycle)
- **Запросы**:
  - Спортивные мотоциклы с мощностью > 150 л.с., ценой < 20000
  - Объединённый список всех ТС с фильтрацией по мощности, объёму, цене

### DB 2: Гоночные результаты (Racing Stats)
- **Таблицы**: `cars`, `classes`, `races`, `results`
- **Связи**: `cars.class` → `classes.class`, `results` связывает гонки и машины
- **Запросы**:
  - Лучшая средняя позиция в классе
  - Автомобиль с минимальной средней позицией
  - Автомобили с позицией лучше средней по классу
  - Классы с большим количеством «слабых» машин (> 3.0 средняя позиция)

### DB 3: Гостиничные бронирования (Hotel Booking)
- **Таблицы**: `hotel`, `room`, `customer`, `booking`
- **Связи**: отель → номера → бронирования ← клиенты
- **Запросы**:
  - Клиенты с бронями в >1 отеле и >2 бронями
  - Клиенты с тратами >500 и бронями в разных отелях
  - Классификация клиентов по предпочитаемому типу отеля (дешёвый / средний / дорогой)

### DB 4: Иерархия сотрудников (Employee Hierarchy)
- **Таблицы**: `employees`, `departments`, `roles`, `projects`, `tasks`
- **Иерархия**: через `ManagerID` (рекурсивные CTE)
- **Запросы**:
  - Все подчинённые Ивана Иванова + проекты/задачи
  - Расширенная информация: количество подчинённых, количество задач
  - Менеджеры (роль = 'Менеджер') с количеством подчинённых >0

## Инструкция по запуску и тестированию

### Требования
- MySQL 8.0+ (поддержка рекурсивных CTE, оконных функций)
- Любой клиент (MySQL Workbench, HeidiSQL, DBeaver, CLI)

### Предупреждение по запуску
Если запускать файл All_MySql_Solution.sql в HeidiSQL выводятся не все резальтаты (только 10 вкладок).
В MySQL Workbench отображаются результаты выполнения всех запросов.

### Запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/sql-data-analysis-projects.git
   cd sql-data-analysis-projects
   ```
   
2. Откройте любой файл init_and_queries.sql в нужной папке.

3. Выполните весь скрипт (он сам создаст БД, таблицы, данные и покажет результаты).

Пример через MySQL CLI:

   mysql -u root -p < db_1_vehicle_shop/init_and_queries.sql

### Проверка результатов

Каждый скрипт содержит SELECT-запросы с ответами на задачи.
Вы увидите таблицы с результатами прямо после выполнения.

Пример ожидаемого вывода для DB1 Task1:

| maker     | model    |
|-----------|----------|
| Yamaha    | YZF-R1   |
